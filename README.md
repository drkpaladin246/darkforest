# Pomodoro Forest

A desktop Pomodoro timer for macOS and Windows that grows a low-poly 3D forest. Each focus session grows one tree on a floating island, from seed to sprout to sapling to full tree. Finish the session and the tree is planted for good. Quit early and it withers.

Everything runs offline. Your data stays in a single JSON file on your computer.

## Features

**Timer**
- Focus, short break and long break cycle (long break every 4 sessions by default)
- Adjustable durations and cycle length
- Large animated progress ring
- Start / pause / skip / reset buttons with keyboard shortcuts
- Global shortcut that works from any app
- Menu bar (macOS) or system tray (Windows) icon with the remaining time and a progress ring
- Desktop notifications plus a chime, with five synthesized sounds (bell, wind chime, marimba, soft gong, birdsong) and a volume control

**Tasks**
- Task list with estimated pomodoros
- Pick the task you're focusing on; each completed session is counted against it

**Stats**
- Sessions and focus time today, current streak, total trees, total focus time, withered count
- Bar chart of the last 7 days
- Unlock progress

**Forest**
- Three.js floating island with soft shadows, gentle wind sway, drifting clouds and a slow bob
- Drag to rotate, scroll or pinch to zoom (mouse and trackpad)
- Sky follows your local time: dawn, day, golden hour, dusk and a starry night with the moon and a lantern glow
- View the forest for today, this week or all time
- The island grows as your forest grows
- All art is generated in code (no copied models or textures)

**Unlocks**

| Unlock | Type | How |
| --- | --- | --- |
| Oak | Tree | From the start |
| Wildflowers | Decoration | 3 sessions |
| Pine | Tree | 5 sessions |
| Mossy rocks | Decoration | 10 sessions |
| Cherry blossom | Tree | 3-day streak |
| Rabbits | Decoration | 15 sessions |
| Birds | Decoration | 5-day streak |
| Palm | Tree | 25 sessions |
| Pond | Decoration | 7-day streak |
| Deer | Decoration | 50 sessions |

Streak unlocks use your best streak ever, so they stay unlocked.

**Settings**
- Auto-start breaks and/or the next focus session
- Notifications on/off, chime, volume
- Light, dark or system theme
- Compact always-on-top mini mode

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| Space | Start / pause |
| S | Skip to the next phase |
| R | Reset the current phase |
| M | Toggle mini mode |
| Esc | Leave mini mode |
| Cmd+Shift+Space (macOS), Ctrl+Shift+Space (Windows) | Start / pause from anywhere |

Skipping or resetting a focus session after the first 10 seconds withers its tree (you'll be asked to confirm). Quitting the app mid-session does the same.

## Run it

You need [Node.js](https://nodejs.org) 20 or newer.

```bash
git clone https://github.com/drkpaladin246/darkforest.git
cd darkforest
npm install
npm start
```

Closing the window keeps the app running in the menu bar / tray so the timer continues. Use **Quit** from the tray menu (or Cmd+Q on macOS) to exit.

## Build installers

Installers are built with [electron-builder](https://www.electron.build). Build each platform on that platform:

```bash
# On a Mac: produces .dmg installers (Apple Silicon and Intel) in dist/
npm run dist:mac

# On Windows: produces a Setup .exe installer in dist/
npm run dist:win
```

The builds are not code-signed, so the first launch shows a warning:

- **macOS:** right-click the app in Applications and choose **Open**, then **Open** again. (Or System Settings > Privacy & Security > Open Anyway.)
- **Windows:** on the SmartScreen prompt click **More info**, then **Run anyway**.

To sign and notarize, add your Apple Developer / Windows code-signing certificates as described in the [electron-builder code signing docs](https://www.electron.build/code-signing).

The app icons in `build/` are generated by `npm run icons` (pure Node, no extra dependencies).

## Where data is stored

| OS | Path |
| --- | --- |
| macOS | `~/Library/Application Support/Pomodoro Forest/pomodoro-forest.json` |
| Windows | `%APPDATA%\Pomodoro Forest\pomodoro-forest.json` |

Delete that file to start a fresh forest.

## Development

```bash
npm test          # unit tests for timer cycle, streaks, stats and unlocks
npm start         # run the app
```

You can also open the UI in a plain browser for quick iteration (data goes to localStorage there):

```bash
python3 -m http.server 8000
# open http://localhost:8000/src/renderer/index.html
# add ?hour=21 to preview the night sky, ?hour=18.3 for sunset
```

### Project layout

```
src/
  main.js            Electron main process: window, tray, global shortcut, notifications, mini mode, storage
  preload.js         Safe bridge between the UI and the main process
  renderer/
    index.html       UI layout
    styles.css       Light and dark themes, mini mode
    app.js           Timer, tasks, stats, settings, keyboard shortcuts
    core.js          Pure logic (cycle, streaks, stats, unlocks, placement), unit tested
    forest.js        Three.js island, trees, decorations, sky and camera controls
    sounds.js        Web Audio chimes
scripts/make-icon.js Generates build/icon.png and tray icons
test/                Node test runner tests
```
